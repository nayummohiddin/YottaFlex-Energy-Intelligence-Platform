# Submission checklist

- [ ] Public GitHub repository created; source pushed (do this from your GitHub account)
- [ ] README has setup/run steps, architecture, rules, data assumptions, and API list
- [ ] Java 17 / Spring Boot backend starts and health endpoint works
- [ ] PostgreSQL schema created and data loaded
- [ ] Python generator creates 20 meters, 90 days of 15-minute readings and 2,000 batches using seed 20261022
- [ ] Ground truth exported separately and not used as features
- [ ] CSV/JSON and SQL seed/export artifacts included or reproducibly generated
- [ ] Primary key, foreign key, enum, date-order, arithmetic, duplicate and lifecycle validations pass
- [ ] Re-run generator twice; compare row counts and checksums
- [ ] Dashboard displays calculated metrics and exception/recommendation evidence
- [ ] Unit, integration and end-to-end tests pass
- [ ] Demo video or screenshots added if allowed by submission portal
- [ ] Repository contains no secrets, personal data, or unlicensed datasets
- [ ] Final submission URL and short project summary submitted
